# ROI & ROAD Calculator 🧮

A responsive and mobile-friendly calculator tool to measure **ROI (Return on Investment)** and **ROAD (Return on Advertising Dollars)** with smart insights, dynamic result highlighting, and visual performance trends using Chart.js.

## 🔍 Features

- ROI and ROAD calculations with real-time results
- Smart insights (positive/negative performance comments)
- Dynamic result styling (green for positive, red for low/negative)
- Currency support for AED 🇦🇪 and USD 🇺🇸
- Net Profit and ROAS included
- Interactive performance chart for up to 5 campaigns
- Clean dark-themed UI with responsive design
